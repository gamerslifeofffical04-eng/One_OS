### ✨ Key Features

* **One UI-Inspired Desktop:** Deep dark surfaces (`#0E111A`), rounded corners, floating bottom dock, and distraction-free ergonomics powered by KDE Plasma 6.
* **Built-In Gemini Corner Pill:** Always-accessible floating `✦ Ask Gemini` pill in the bottom-right corner with instant **Circle to Search** (`◎`) screen capture.
* **Fluid 4-Dot Boot Experience:** Smooth Android-style 4-dot morphing boot animation transitioning directly to the desktop.
* **Zero-Friction Setup:** Instant live boot and streamlined Calamares installer with zero forced password prompts.
* **Over-The-Air (OTA) Updates:** Lightweight delta updates delivered directly from GitHub Releases without requiring full ISO reinstalls.
* **Optimized for Everyday Hardware:** Pre-configured `zstd` ZRAM compression, disabled background file-indexing overhead, and out-of-the-box Intel Wi-Fi & graphics support.

### 💻 Minimum System Requirements

| Component | Minimum | Recommended |
| :--- | :--- | :--- |
| **Processor** | 64-bit Dual-Core (Intel Core i3 / AMD Ryzen 3) | Quad-Core x86_64 |
| **Memory (RAM)** | 4 GB (with built-in ZRAM) | 8 GB or more |
| **Storage** | 16 GB | 32 GB SSD |
| **Graphics** | OpenGL 2.1+ / Intel HD Graphics | Intel UHD / Iris or AMD Radeon |

### 🚀 Quick Start

1. Download the latest **`OneOS-x86_64.iso`** from the [**Releases**](https://github.com/vga4400x4400-blip/OneOS/releases/latest) page.
2. Flash it to a USB drive using **Rufus**, **BalenaEtcher**, or **Ventoy**.
3. Boot from USB—OneOS launches straight into the live desktop. Click **Install OneOS** on the desktop to install to your drive.
